Cada post empieza como un archivo Markdown con frontmatter validado.

## Metadatos obligatorios

Título y descripción son obligatorios: sin ellos el build falla. Así nunca se publica un post sin metadatos SEO.

## Etiquetas

Las etiquetas generan páginas propias enlazadas entre sí, lo que ayuda a la indexación.
