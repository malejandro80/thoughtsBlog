# i18n — English/Spanish Language Switching

## Overview

Add internationalization to the thoughtsBlog Astro site, supporting English and Spanish with path-prefixed URLs. Every blog post has translated pairs. UI strings are extracted to dictionaries. A language toggle (ES | EN) is added to the header.

## Approach

Astro's built-in i18n routing with `routing.prefix`. Content lives in `src/content/{locale}/blog/`. UI strings in `src/i18n/{locale}.ts` dictionaries.

## URL Structure

- Spanish (default): `/blog/post-slug` (no prefix)
- English: `/en/blog/post-slug`

## Astro Config

```js
// astro.config.mjs
export default defineConfig({
  i18n: {
    defaultLocale: 'es',
    locales: ['es', 'en'],
    routing: {
      prefixDefaultLocale: false,
    },
  },
});
```

## Content Structure

```
src/content/
  es/blog/
    sobre-poder-y-gobernanza.md
  en/blog/
    reflections-on-governance.md
```

Posts keep their original filenames in each locale directory. The content schema uses Astro's automatic locale detection.

## UI Strings

Dictionaries in `src/i18n/es.ts` and `src/i18n/en.ts`:

```ts
export default {
  nav: { home: 'Inicio', blog: 'Blog', portfolio: 'Portafolio' },
  home: { featured: 'Posts destacados', viewAll: 'Ver todos los posts →' },
  blog: { title: 'Todos los posts', archive: 'Archivo completo de todos los posts del blog.' },
  back: { home: 'Inicio', blog: 'Todos los posts' },
  post: { updated: 'Actualizado:' },
  notFound: { title: '404', message: 'No encontré esta página.', back: 'Volver al inicio' },
  footnote: 'La intención principal de este post es pensar y hacer pensar...',
  footer: { rss: 'RSS' },
} as const;
```

## Helper

`src/utils/locale.ts` exports `useTranslations(locale)` that returns the dictionary for the given locale.

Components access translations via:
```astro
const t = useTranslations(Astro.currentLocale as Locale);
```

## Language Switcher

Added to `Header.astro` as a text toggle (`ES | EN`). Uses `getRelativeLocaleUrl()` from `astro:i18n` to link to the same page in the other locale.

## Locale Detection

- First visit: browser `Accept-Language` header → Astro middleware or config default
- Persistence: `localStorage` via inline `<script>` in `<head>`
- Toggle: updates `localStorage` and navigates to other locale URL
