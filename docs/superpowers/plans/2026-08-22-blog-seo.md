# Blog Markdown SEO (Astro + GitHub Pages) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Blog personal en Markdown con Astro 5, optimizado para SEO, desplegado automáticamente en GitHub Pages con dominio propio `thoughts.miguelintech.com`.

**Architecture:** Sitio 100% estático (SSG). Posts como archivos `.md` en Content Collections con validación zod de frontmatter. Un layout base concentra todos los metadatos SEO. Deploy vía GitHub Actions al hacer push a `main`.

**Tech Stack:** Astro 5, @astrojs/sitemap, @astrojs/rss, TypeScript strict, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-08-22-astro-blog-design.md`

**Nota sobre verificación:** Al ser un sitio estático sin JS en cliente, la "prueba" de cada tarea es `npm run build` exitoso + inspección del HTML generado en `dist/` con `grep`/`cat`. La validación zod actúa como test automático del contenido.

### Task 3: Utilidades de posts y fechas

**Files:**
- Create: `src/utils/posts.ts`
- Create: `src/utils/formattedDate.ts`

- [ ] **Step 1: Crear `src/utils/posts.ts`**

```ts
import { getCollection } from 'astro:content';
import type { CollectionEntry } from 'astro:content';

/** Devuelve los posts publicados ordenados por fecha descendente.
 * En producción excluye los drafts; en desarrollo los incluye para poder previsualizarlos. */
export async function getPublishedPosts(): Promise<CollectionEntry<'blog'>[]> {
  const posts = await getCollection('blog', ({ data }) =>
    import.meta.env.PROD ? !data.draft : true,
  );
  return posts.sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
}

/** Devuelve las etiquetas únicas de una lista de posts, ordenadas alfabéticamente. */
export function getAllTags(posts: CollectionEntry<'blog'>[]): string[] {
  return [...new Set(posts.flatMap((post) => post.data.tags))].sort();
}
```

- [ ] **Step 2: Crear `src/utils/formattedDate.ts`**

/** Formatea una fecha en español: "22 de agosto de 2026". */
export function formattedDate(date: Date): string {

    year: 'numeric',
    month: 'long',
    day: 'numeric',
  });
}

### Task 7: Imagen OG por defecto

**Files:**
- Create: `public/og-default.png`

Se genera un PNG sólido 1200x630 (tamaño recomendado para Open Graph) con Python stdlib, sin dependencias. Es un placeholder funcional; el usuario podrá reemplazarlo por una imagen diseñada más adelante.

- [ ] **Step 1: Generar el PNG**

Run:

```bash
python3 - <<'PY'
import struct, zlib

W, H = 1200, 630
row = b'\x00' + b'\x25\x63\xeb' * W
raw = row * H

def chunk(t, d):
    c = t + d
    return struct.pack('>I', len(d)) + c + struct.pack('>I', zlib.crc32(c))

png = (
    b'\x89PNG\r\n\x1a\n'
    + chunk(b'IHDR', struct.pack('>IIBBBBB', W, H, 8, 2, 0, 0, 0))
    + chunk(b'IDAT', zlib.compress(raw))
    + chunk(b'IEND', b'')
)
with open('public/og-default.png', 'wb') as f:
    f.write(png)
print('ok')
PY
```

### Task 9: Página de post individual con JSON-LD

**Files:**
- Create: `src/pages/blog/[slug].astro`

- [ ] **Step 1: Crear `src/pages/blog/[slug].astro`**

```astro
---
import type { CollectionEntry } from 'astro:content';
import { render } from 'astro:content';
import BaseLayout from '../../layouts/BaseLayout.astro';
import { SITE } from '../../consts';
import { getPublishedPosts } from '../../utils/posts';
import { formattedDate } from '../../utils/formattedDate';

export async function getStaticPaths() {
  const posts = await getPublishedPosts();
  return posts.map((post) => ({
    params: { slug: post.id },
    props: { post },
  }));
}

interface Props {
  post: CollectionEntry<'blog'>;
}

const { post } = Astro.props;
const { Content } = await render(post);
const canonical = new URL(`/blog/${post.id}/`, SITE.url);
const jsonLd = {
  '@context': 'https://schema.org',
  '@type': 'BlogPosting',
  headline: post.data.title,
  description: post.data.description,
  datePublished: post.data.pubDate.toISOString(),
  dateModified: (post.data.updatedDate ?? post.data.pubDate).toISOString(),
  author: { '@type': 'Person', name: SITE.author },
  image: new URL('/og-default.png', SITE.url).toString(),
  mainEntityOfPage: canonical.toString(),
  keywords: post.data.tags.join(', '),
};
---

<BaseLayout
  title={`${post.data.title} · ${SITE.title}`}
  description={post.data.description}
  type="article"
  publishedTime={post.data.pubDate}
  modifiedTime={post.data.updatedDate}
  tags={post.data.tags}
  jsonLd={jsonLd}
>
  <article>
    <header class="post-header">
      <h1>{post.data.title}</h1>
      <time datetime={post.data.pubDate.toISOString()}>{formattedDate(post.data.pubDate)}</time>
      {post.data.updatedDate && (
        <p>
          Actualizado:
          <time datetime={post.data.updatedDate.toISOString()}>
            {formattedDate(post.data.updatedDate)}
          </time>
        </p>
      )}
      <ul class="tags">
        {post.data.tags.map((tag) => <li><a href={`/tags/${tag}/`}>#{tag}</a></li>)}
      </ul>
    </header>

    <div class="prose">
      <Content />
    </div>
  </article>
</BaseLayout>
```

- [ ] **Step 2: Crear `.github/workflows/deploy.yml`**

Workflow oficial de Astro para GitHub Pages:

```yaml
name: Desplegar a GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Instalar dependencias y compilar
        uses: withastro/action@v3

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Publicar en GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
