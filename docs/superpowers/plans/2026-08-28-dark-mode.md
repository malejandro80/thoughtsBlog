# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dark mode to the thoughtsBlog Astro site with separate CSS files per theme, a toggle button, OS preference detection, and localStorage persistence.

**Architecture:** Split CSS variables into theme-specific files (`theme-light.css`, `theme-dark.css`). An inline script in `<head>` reads preference before paint to prevent FOUC. A toggle button in the header swaps the `<link>` href and persists choice.

**Tech Stack:** Astro, CSS custom properties, vanilla JavaScript (no frameworks)

---

## File Structure

| File | Action | Purpose |

### Task 4: Add theme loading to `BaseLayout.astro`

**Files:**
- Modify: `src/layouts/BaseLayout.astro:36-71`

- [ ] **Step 1: Add theme `<link>` tag and inline init script in `<head>`**

In `BaseLayout.astro`, inside the `<head>` tag, add the following **before** the existing `<meta name="theme-color">` line (line 49):

```astro
    <link rel="stylesheet" id="theme-css" href="/theme-light.css" />
    <script is:inline>
      (function () {
        var t = localStorage.getItem('theme')
          || (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
        document.documentElement.dataset.theme = t;
        var link = document.getElementById('theme-css');
        if (link) link.href = '/theme-' + t + '.css';
        var meta = document.querySelector('meta[name="theme-color"]');
        if (meta) meta.content = t === 'dark' ? '#0f172a' : '#f8fafc';
      })();
    </script>
```

```astro
          <circle cx="12" cy="12" r="5"></circle>
          <line x1="12" y1="1" x2="12" y2="3"></line>
          <line x1="12" y1="21" x2="12" y2="23"></line>
          <line x1="4.22" y1="4.22" x2="5.64" y2="5.64"></line>

          <line x1="1" y1="12" x2="3" y2="12"></line>
          <line x1="21" y1="12" x2="23" y2="12"></line>
          <line x1="4.22" y1="19.78" x2="5.64" y2="18.36"></line>
          <line x1="18.36" y1="5.64" x2="19.78" y2="4.22"></line>
        </svg>
        <svg class="icon-moon" xmlns="http://www.w3.org/2000/svg" width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
          <path d="M21 12.79A9 9 0 1 1 11.21 3 7 7 0 0 0 21 12.79z"></path>
        </svg>
      </button>
    </div>
  </div>
</header>

<script is:inline>
  (function () {
    var btn = document.getElementById('theme-toggle');
    if (!btn) return;

    function updateButton(theme) {
      btn.setAttribute('aria-pressed', theme === 'dark');
      btn.classList.toggle('is-dark', theme === 'dark');
    }

    function setTheme(theme) {
      document.documentElement.dataset.theme = theme;
      var link = document.getElementById('theme-css');
      if (link) link.href = '/theme-' + theme + '.css';
      var meta = document.getElementById('theme-color');
      if (meta) meta.content = theme === 'dark' ? '#0f172a' : '#f8fafc';
      localStorage.setItem('theme', theme);
      updateButton(theme);
    }

    var current = document.documentElement.dataset.theme || 'light';
    updateButton(current);

    btn.addEventListener('click', function () {
      var next = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
      setTheme(next);
    });
  })();
</script>
```
